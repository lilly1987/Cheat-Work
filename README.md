# Cheat Work

림이 작업을 예약하거나 수행하지 않고, 작업 지정을 등록하는 즉시 결과를 처리하는 RimWorld 1.7 모드입니다. 채굴은 지정 도구의 FloodFill이 끝난 다음 게임 틱에 처리하여 다른 모드의 영역 탐색과 중첩되지 않도록 합니다.

지원 항목:

- 채굴 및 광맥 채굴
- 건물 해체
- 바닥 및 기초(브리지) 제거
- 식물 제초 및 수확
- 파종 구역에서 작물 선택 또는 구역 확장 시 즉시 파종
- ‘지붕 없음’ 구역으로 지정한 지붕 제거
- 음식 제작 시 조리로 인한 식중독 방지
- 플레이어 작업으로 생성된 아이템의 저장고 즉시 이동

게임 내 **모드 설정 > Cheat Work**에서 즉시 작업 처리와 결과물 저장 기능을 각각 켜거나 끌 수 있습니다. 결과물 저장은 기본 활성화되어 있으며, 플레이어 작업 중 생성된 운반 가능 아이템(제작품, 낚시·수확 산출물, 해체·채굴 부산물 등)을 바닐라 저장 필터와 우선순위에 맞는 저장고 칸으로 즉시 이동합니다. 이미 유효한 저장고에 있거나, 허용되는 저장 칸이 없으면 이동하지 않습니다. 스택은 바닐라 배치 로직으로 합쳐집니다.

음식 제작으로 발생하는 오염된 주방 및 미숙한 요리사 식중독은 방지하지만, 상한 음식이나 위험한 식품 섭취로 인한 식중독은 변경하지 않습니다. 광맥 채굴 완료 시 주변 안개가 걷힌 칸에서 연결된 동일 광맥에도 `MineVein` 지정을 추가하고, 추가된 지정은 다음 게임 틱에 처리합니다. 파종은 파종 구역의 작물을 선택하거나 해당 구역에 칸을 추가하는 즉시 진행됩니다. 계절, 재배 가능 조건, 주변 식물 제한을 확인합니다. 결과물 생성, 지형 변경, 지붕 붕괴 확인은 바닐라 완료 동작을 따릅니다. 수확, 벌목 및 파종의 바닐라 기록/이벤트에만 플레이어 식민자를 참조하며, 작업이나 예약은 만들지 않습니다.

Harmony가 필요합니다. 소스 프로젝트는 .NET 10 SDK와 게임 폴더의 `Assembly-CSharp.dll` 및 `UnityStubs.dll`, Steam 워크숍의 Harmony 1.7 어셈블리를 참조합니다. 설치 경로가 다르면 빌드 시 `GameRoot`와 `GameManagedPath` MSBuild 속성을 지정하세요.

모드 폴더의 `Build.bat`을 실행하면 Release DLL을 `Assemblies\CheatWork.dll`에 빌드합니다. 명령 프롬프트에서 일시 정지 없이 실행하려면 `Build.bat /nopause`를 사용하세요.
